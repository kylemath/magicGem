\section*{Highlights}
\begin{itemize}
\item Axial moment conditions for magic squares link to Prouhet--Tarry--Escott systems.
\item The permutation moment threshold satisfies $\sqrt{2n} \lesssim k^*(n) \lesssim 2\sqrt{2n\log n}$.
\item Exact threshold values $k^*(n)$ are determined for all orders $3 \le n \le 40$.
\item Exact variances and limit laws are derived for random permutation line energies.
\item Exactly $14{,}639{,}440$ order-$4$ arrangements satisfy the four-term energy $E_4=0$.
\end{itemize}
