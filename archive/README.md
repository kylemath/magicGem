# Magic Gems & Magic Squares — Research Archive

This directory preserves historical drafts, review materials, submission checklists, and unique research scripts consolidated from the legacy 2025 repositories (`kylemath/magicSquare` and `kylemath/MagicGemNotes`) as well as the pre-split stages of `kylemath/magicGem`.

## Directory Structure

| Subdirectory | Origin & Contents |
| :--- | :--- |
| `pre_split/` | Original pre-split 1-paper arXiv manuscripts (`arxiv_submission/`, `arxiv_submission_V1_Backup/`, `arxivCompressed/`, `olderTex/`) and internal/external review rounds (`internalReview/`, `externalReview/`) prior to splitting the monograph into Papers A, B, and C. |
| `MagicGemNotes_2025/` | All 103 unique scripts, TeX drafts, markdown notes, interactive prototypes, and datasets imported from `kylemath/MagicGemNotes` (`clean_reproduction/`). |
| `magicSquare_2025/` | All 319 unique Python analysis scripts, TeX drafts (`DraftPapers/`), axial/covariance/spinning-top explorations (`Analysis/`), and summary datasets imported from `kylemath/magicSquare`. |
| `submission_notes/` | Submission checklists, journal package manifests, cover letters, and handoff notes (`AGENT_HANDOFF.md`, `JOURNAL_SUBMISSION_PACKAGE.md`, `UPLOAD_CHECKLIST.md`, `cover_letter_paperC.txt`, `submit.html`). |
