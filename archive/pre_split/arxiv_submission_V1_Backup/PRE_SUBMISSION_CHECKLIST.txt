arXiv Pre-Submission Checklist
================================

BEFORE UPLOADING TO ARXIV:
---------------------------

[x] 1. FILE VERIFICATION
   [x] All LaTeX source files are present (main.tex + all sections)
   [x] All figure files referenced in the document exist
   [x] Bibliography file (references.bib) is included
   [x] No unnecessary files (data files, scripts, etc.) are included
       * NOTE: Do NOT upload the text files (README.txt, SUMMARY.txt, etc.) to arXiv.
   [x] File structure matches what's expected (sections/, figures/ subdirectories)

[?] 2. LATEX COMPILATION (Verify locally if possible)
   [ ] Document compiles locally without errors
   [ ] All figures display correctly
   [ ] Bibliography compiles correctly
   [ ] No missing references
   [ ] Page numbers and formatting look correct

[x] 3. CONTENT VERIFICATION
   [x] Title matches the paper
   [x] Abstract is complete and accurate
   [x] All authors are listed correctly
   [x] Contact information is current
   [x] Keywords are appropriate

[x] 4. METADATA PREPARATION
   [x] Primary subject class: math.CO (Combinatorics)
   [x] Secondary subject class: cs.DM, cs.CG (Updated)
   [x] MSC codes prepared: 05B15, 52B11, 62H20
   [x] Abstract text ready to copy/paste
   [x] Keywords ready: Magic squares, convex polyhedra, covariance, energy landscape, combinatorial geometry

[x] 5. FIGURE VERIFICATION
   [x] All PDF figures are properly embedded (not just linked)
   [x] PNG figures are readable and not corrupted
   [x] Figure paths in LaTeX match actual file locations
   [x] All figures are referenced in the text

[x] 6. BIBLIOGRAPHY
   [x] All references in references.bib are properly formatted
   [x] No missing or broken URLs
   [x] All cited references appear in the bibliography
   [x] Bibliography style is appropriate (plain)

[x] 7. ARXIV-SPECIFIC CHECKS
   [x] No non-standard packages that might not be available
   [x] All commented packages have alternatives or are not needed
   [x] Hyperlinks work correctly (hyperref package is standard)
   [x] No external dependencies that require special setup

[ ] 8. FINAL REVIEW (You must do this)
   [ ] Read through the entire compiled PDF one more time
   [ ] Check for typos and formatting issues
   [ ] Verify all mathematical notation renders correctly
   [ ] Ensure all tables and figures are properly captioned
   [ ] Check that section references work correctly

AFTER UPLOADING TO ARXIV:
-------------------------

[ ] 9. POST-UPLOAD VERIFICATION
   [ ] arXiv successfully compiled the document
   [ ] Review the auto-generated PDF on arXiv
   [ ] Check that all figures appear correctly
   [ ] Verify bibliography compiled correctly
   [ ] Ensure page numbers and formatting are correct
   [ ] Check that hyperlinks work in the arXiv PDF

[ ] 10. SUBMISSION
    [ ] All metadata fields are filled correctly
    [ ] Abstract matches the paper
    [ ] Subject classifications are correct
    [ ] License is selected (if required)
    [ ] Ready to submit!
